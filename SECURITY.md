# Безопасность BeamNG Mod Downloader

## Поддерживаемые версии

Обслуживается только **последний опубликованный release**. Исправления
безопасности выходят в новых версиях; отдельные backport-обновления не делаются.

## Область ответственности

Безопасность **приложения** (обработка URL, целостность загружаемых архивов,
файловая система, ledger/config, Tauri boundary, CI/release pipeline).

**Моды и сторонние источники выходят за рамки наших гарантий.** Мод BeamNG
может содержать исполняемый Lua-код. Приложение загружает архивы из
недоверенных источников (WorldOfMods, произвольные GitHub-репозитории) и не
проверяет их содержимое: найденный мод не следует считать безопасным.
Перед установкой приложение показывает явное предупреждение.

## Сообщение об уязвимости

Используйте **частный канал** — GitHub Security Advisories:

https://github.com/arcticlore/beamng-mod-downloader/security/advisories/new

Публичные issue с описанием активной уязвимости мы просим не открывать.

В отчёте укажите:

- затронутую версию и платформу;
- шаги воспроизведения;
- ожидаемое и фактическое поведение;
- при наличии — предлагаемый фикс (patch).

Резол высшего приоритета — критические/высокие уязвимости (RCE, произвольное
скачивание/удаление файлов, SSRF, обход модели доверия). SLA — реагирование в
течение 48 часов.

## Как сообщить о проблеме с модом или источником

Обращайтесь к автору мода/источника. Приложение не отвечает за содержимое
сторонних архивов.
